# Vertex AI Setup Guide

This guide explains how to set up and use the amendments mapper with Google Cloud Vertex AI.

## Prerequisites

1. **Google Cloud Platform Account**
   - Active GCP account with billing enabled
   - A GCP project created

2. **Vertex AI API Enabled**
   - Enable Vertex AI API in your GCP project
   - Go to: https://console.cloud.google.com/apis/library/aiplatform.googleapis.com

3. **Authentication**
   - Install and configure Google Cloud SDK (gcloud)
   - Authenticate your application

## Setup Steps

### 1. Install Google Cloud SDK

```bash
# For Linux
curl https://sdk.cloud.google.com | bash
exec -l $SHELL

# For macOS
brew install google-cloud-sdk

# Initialize gcloud
gcloud init
```

### 2. Authenticate

```bash
# Application Default Credentials (recommended)
gcloud auth application-default login

# Or use a service account (for production)
export GOOGLE_APPLICATION_CREDENTIALS="/path/to/service-account-key.json"
```

### 3. Enable Vertex AI API

```bash
# Set your project
gcloud config set project YOUR_PROJECT_ID

# Enable Vertex AI API
gcloud services enable aiplatform.googleapis.com
```

### 4. Install Python Dependencies

```bash
pip install -r requirements.txt
```

### 5. Configure Environment Variables

```bash
# Required
export GCP_PROJECT_ID="your-project-id"

# Optional (defaults to us-central1)
export GCP_LOCATION="us-central1"
```

## Running the Amendments Mapper

### Basic Usage

```bash
# Set environment variables
export GCP_PROJECT_ID="your-project-id"

# Run the mapper
python amendments_mapper.py
```

### Full Example

```bash
# 1. Authenticate
gcloud auth application-default login

# 2. Set project
export GCP_PROJECT_ID="my-gcp-project"
export GCP_LOCATION="us-central1"

# 3. Ensure input file exists
ls parsed_gos.json

# 4. Run the mapper
python amendments_mapper.py

# 5. Check output
cat amendments_mapped.json
```

## Available GCP Regions

Vertex AI is available in the following regions:
- `us-central1` (Iowa) - Default
- `us-east4` (Northern Virginia)
- `us-west1` (Oregon)
- `europe-west4` (Netherlands)
- `asia-southeast1` (Singapore)

Choose the region closest to you for best performance.

## Models Available

The script uses `gemini-1.5-flash` by default. You can modify the model in the code:

```python
self.model = GenerativeModel('gemini-1.5-flash')  # Fast and cost-effective
# Or
self.model = GenerativeModel('gemini-1.5-pro')    # More capable
```

## Cost Considerations

Vertex AI charges based on:
- **Input tokens**: Text sent to the model
- **Output tokens**: Text generated by the model

**Gemini 1.5 Flash Pricing** (as of 2024):
- Input: $0.00001875 per 1K characters
- Output: $0.0000375 per 1K characters

**Cost Estimation**:
- Processing 100 GOs with ~500 words each
- Estimated cost: ~$0.50 - $2.00

## Troubleshooting

### Authentication Errors

```bash
# Error: Could not automatically determine credentials
Solution: Run `gcloud auth application-default login`
```

### Permission Denied

```bash
# Error: Permission denied on Vertex AI API
Solution: Ensure you have the required IAM roles:
- Vertex AI User (roles/aiplatform.user)
- Service Account User (if using service account)
```

### Quota Exceeded

```bash
# Error: Quota exceeded
Solution:
1. Check quotas: https://console.cloud.google.com/iam-admin/quotas
2. Request quota increase if needed
3. Add rate limiting in the code (already implemented with 1s delay)
```

### Region Not Supported

```bash
# Error: Invalid region
Solution: Use one of the supported regions listed above
```

## Service Account Setup (Production)

For production deployments, use a service account:

```bash
# 1. Create service account
gcloud iam service-accounts create amendments-mapper \
    --display-name="Amendments Mapper Service Account"

# 2. Grant Vertex AI permissions
gcloud projects add-iam-policy-binding YOUR_PROJECT_ID \
    --member="serviceAccount:amendments-mapper@YOUR_PROJECT_ID.iam.gserviceaccount.com" \
    --role="roles/aiplatform.user"

# 3. Create and download key
gcloud iam service-accounts keys create ~/amendments-mapper-key.json \
    --iam-account=amendments-mapper@YOUR_PROJECT_ID.iam.gserviceaccount.com

# 4. Use the key
export GOOGLE_APPLICATION_CREDENTIALS="$HOME/amendments-mapper-key.json"
export GCP_PROJECT_ID="YOUR_PROJECT_ID"

# 5. Run the script
python amendments_mapper.py
```

## Environment Variables Reference

| Variable | Required | Default | Description |
|----------|----------|---------|-------------|
| `GCP_PROJECT_ID` | Yes | None | Your GCP project ID |
| `GCP_LOCATION` | No | `us-central1` | Vertex AI region |
| `GOOGLE_APPLICATION_CREDENTIALS` | No* | Auto-detected | Path to service account key |

*Required only if not using gcloud auth
